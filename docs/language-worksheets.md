# Spelling and Grammar

The language scripts use the existing Python/ReportLab environment and support
suggested US-English grades 1-5. They automatically paginate: each printed word
or sentence stays with all its writing lines. Instructions repeat on every page.
All text defaults to bundled Andika; use `--font Helvetica`, another standard PDF
font name, or a local `.ttf` path to choose a different face. See
[Worksheet Fonts](fonts.md) for options, embedding, and licensing.

## Rote Spelling

```sh
worksheet_venv/bin/python spelling_practice.py --grade 1
worksheet_venv/bin/python spelling_practice.py --grade 3 --count 12 --seed 42
worksheet_venv/bin/python spelling_practice.py --grade 2 --words rain train paint --lines-per-word 3
worksheet_venv/bin/python spelling_practice.py --grade 5 --line-style guided --output grade5.pdf
```

Each word appears in clear, 22-point print above its practice lines. The default
is 10 randomly selected words without replacement and two writing lines per
word. `--words` uses all supplied words in their original order instead; it
cannot be combined with `--count` or `--word-list`. Explicit words must contain
1-30 lowercase ASCII letters. `--seed` makes selection repeatable without
changing the application's global random state.

The default output is `spelling_practice.pdf`. Other controls are `--font-size`,
`--instructions`, `--lines-per-word`, and `--line-style`:

| Style | Appearance | Default For |
| --- | --- | --- |
| `guided` | Solid top and bottom rails with a dashed middle rail | Grades 1-2 |
| `baseline` | A single solid bottom line | Grades 3-5 |

Either style can be selected at any grade. Use `--instructions ""` to omit the
directions. Increasing font size or practice-line count may produce more pages;
settings that cannot fit even one exercise on a page are rejected before the
PDF is opened. For grammar generation, these static layout checks also run
before a model request is made.

## Word Lists

`worksheet/data/words.json` contains 40 words per grade, 200 in total. These are
**project-authored starter lists**, not a copied third-party dictionary, official
curriculum, standardized grade assessment, or exhaustive vocabulary. They contain
words rather than definitions or part-of-speech annotations. Grade assignments
are suggestions requiring teacher or parent review and adjustment.

| Grade | General Emphasis |
| --- | --- |
| 1 | Short vowels, common consonant combinations, and early irregular words |
| 2 | Vowel teams, r-controlled vowels, and familiar longer words |
| 3 | Endings, plurals, common suffixes, and everyday vocabulary |
| 4 | Prefixes, suffixes, and school-subject vocabulary |
| 5 | Longer words, more complex spelling patterns, and academic vocabulary |

Use a curriculum-specific replacement with `--word-list my-words.json`. Only
the requested grade must be present; its words must be unique and non-empty:

```json
{
  "language": "en-US",
  "source": "Describe the source and its usage rights here",
  "grades": {
    "2": ["rain", "train", "paint"]
  }
}
```

For a three-word list, pass `--count 3` or less. `language` and `source` are
provenance metadata; the loader validates the selected `grades` entry. No word
list is downloaded or generated by an LLM at runtime.

## Grammar Practice

The first grammar activity teaches **capitalization and final periods**. A bank
contains correct sentences; the worksheet lowercases them and removes their
final periods. Internal commas and apostrophes remain unchanged. The original
sentences form the optional answer key.

Start offline with the project-authored example bank:

```sh
worksheet_venv/bin/python grammar_practice.py --grade 2 \
  --sentences docs/examples/grade2-sentences.json \
  --answer-key grammar_answers.pdf
```

Generate new sentences explicitly through your configured OpenCode installation:

```sh
worksheet_venv/bin/python grammar_practice.py --grade 2 \
  --model PROVIDER/MODEL --count 8 --timeout 180 \
  --save-sentences grade2-sentences.json \
  --answer-key grammar_answers.pdf
```

Replace `PROVIDER/MODEL` with an identifier from your OpenCode setup. The script
requires either `--model` or `--sentences`; there is no implicit network call.
Generated requests default to 8 sentences. With a local bank, all its sentences
are used; optional `--count` checks the bank's exact count rather than sampling it.

To use an **already-running OpenCode server**, provide its IP address or hostname
and port:

```sh
worksheet_venv/bin/python grammar_practice.py --grade 2 \
  --model PROVIDER/MODEL --server 127.0.0.1:4096 \
  --save-sentences grade2-sentences.json --answer-key grammar_answers.pdf
```

`--server` accepts `host:port`, `http://host:port`, or `https://host:port`, including
bracketed IPv6 such as `[::1]:4096`. A bare address uses HTTP. An explicit port
between 1 and 65535 is required; URL credentials, paths, queries, and fragments
are rejected (a trailing slash is allowed). Use HTTPS for remote connections
carrying credentials or sensitive data. For basic authentication, set
`OPENCODE_SERVER_PASSWORD` and, if needed, `OPENCODE_SERVER_USERNAME` in the
environment; the default username is `opencode`. Credentials are not command-line
arguments and are not stored by the worksheet application.

The CLI passes the address through OpenCode's `--attach` option, creating a fresh
session rather than continuing an existing conversation. The model must be
available on the server. The server's default agent, working directory, provider
credentials, plugins, permissions, and sharing policy apply. Client-side agent
configuration cannot reconfigure an existing server: **use a trusted server with
tools denied and sharing disabled for text-only generation**. No local directory
or files are sent to the server. `--server` cannot be combined with `--sentences`.
Without `--server`, standalone local execution is unchanged. Attachment failures
never fall back to starting local generation.

A new session appearing in the web UI does not prove generation succeeded.
OpenCode creates a session before submitting the prompt with the selected model;
model lookup, provider requests, or event streaming can still fail afterward.
Use the exact `provider/model` ID configured on that instance, including any
prefix such as `gpt-`. The adapter reports structured model-not-found errors even
when OpenCode exits nonzero, but does not print raw provider responses or stderr.

Bare server addresses always use HTTP. For a TLS proxy, supply an explicit
`https://host:port` URL; changing the port alone does not enable TLS. If using a
direct HTTP backend instead, keep its actual backend port and HTTP scheme.

### Container Launchers

If OpenCode runs inside a container, select the command used to launch its CLI:

```sh
worksheet_venv/bin/python grammar_practice.py --grade 2 \
  --model PROVIDER/MODEL --server 127.0.0.1:4096 \
  --opencode-command "nvim_shell -c 'opencode {args}'"
```

For `nvim_shell -c`, all OpenCode options must be inside the single command-string
argument. The `{args}` placeholder is replaced with the shell-quoted OpenCode
arguments, producing a command shaped like
`nvim_shell -c 'opencode --pure run --attach http://127.0.0.1:4096 --format json ...'`.
The full prompt remains one argument to OpenCode, even when it contains spaces,
quotes, or shell metacharacters. Put `{args}` as an **unquoted shell word inside
the command text**, exactly as shown; do not add inner quotes around the placeholder.
Only one placeholder is allowed, and it cannot appear in the launcher executable.

Ordinary prefixes without `{args}`, such as `opencode` or an argv-forwarding
wrapper, still receive OpenCode options as separately appended arguments. Use the
template form for command-string launchers; `nvim_shell -c opencode` alone does
not put the appended options inside the command string.
Omit `--server` to launch standalone OpenCode through the same wrapper.
When using a container launcher, the server address is resolved **inside the
container**: `127.0.0.1` refers to that container, not necessarily the host.

Repeat `--opencode-command` to try multiple launchers in order:

```sh
worksheet_venv/bin/python grammar_practice.py --grade 2 \
  --model PROVIDER/MODEL \
  --opencode-command "opencode" \
  --opencode-command "nvim_shell -c 'opencode {args}'"
```

Explicit candidates replace the default single `opencode` command. Fallback
occurs only when the operating system cannot find a launcher executable (or its
required interpreter). Once a launcher starts, any failure, timeout, malformed
response, or interruption stops the operation. In particular, a wrapper exiting
with code 127 because OpenCode is absent inside the container does **not** trigger
fallback. This avoids duplicate model requests and charges.

Launchers use POSIX shell quoting to preserve arguments and paths containing
spaces, and the script never starts an implicit shell. Ordinary prefixes have
no variable expansion, pipes, redirects, or shell aliases/functions. A launcher
explicitly using `-c` interprets the supplied command text through its own shell;
only use trusted templates. Generated arguments substituted for `{args}` are
quoted for one POSIX-shell interpretation, not nested shell commands.
The first token must be an executable available on
`PATH` or an executable file path; relative executable paths resolve against the
directory where the worksheet command was invoked. For a launcher path with
spaces, quote that executable within the command option as well.
If `nvim_shell` is only a shell function or alias, provide an executable wrapper
that forwards arguments instead. Do not put secrets in command prefixes.

Launchers must work noninteractively with stdin closed, preserve every appended
argument (including the entire prompt), and emit raw OpenCode JSONL on stdout
without startup banners or terminal escape sequences. They must forward relevant
`OPENCODE_*` environment variables into the container for authentication and
standalone agent configuration. The script's temporary host working directory
may not exist inside the container; the wrapper must select a suitable isolated
container directory. Client timeout/interruption stops the local launcher but
may not stop container or server work. `--opencode-command` requires `--model`
and cannot be combined with `--sentences`.

Defaults are `grammar_practice.pdf`, 16-point prompts, and two lines per sentence.
Use `--output`, `--font-size`, `--lines-per-sentence`, `--line-style`, and
`--instructions` to customize the result. Line-style defaults match spelling.

Saved sentence-bank format:

```json
{
  "grade": 2,
  "sentences": ["The small bird can sing.", "I like to read."]
}
```

Banks must match the requested grade and contain 1-40 distinct sentences. Each
sentence must have 3-15 words, at most 120 ASCII characters, a capital first
letter, and a final period. Only letters, single spaces, commas, and apostrophes
are accepted inside the sentence. Multiple sentences within one entry, markdown
fences, malformed JSON, and unexpected counts are rejected.

**Review generated sentences and answer keys before giving them to a student.**
Validation checks structure, not factual correctness, grammar, age suitability,
or educational quality. The source sentence is a suggested answer, not proof
that all other capitalizations would be wrong. Save and edit the JSON bank for
reviewed, reproducible offline reuse.

### OpenCode Boundary

The adapter targets the installed CLI's `opencode --pure run --format json`
interface, inspected on version `1.18.29-mkchad.1`. A compatible installation
must support `--pure`, raw JSON events, and the named-agent/configuration options.
It uses your existing provider credentials; the worksheet application does not
load or store credentials itself. LLM calls may incur provider charges, and
OpenCode retains its normal local session history.

Each CLI call uses a unique temporary local working directory and fresh session.
Standalone calls disable project configuration and plugins through `--pure` and
the default plugin flag, and request a tool-denied text agent. Attached calls use
the existing server's configuration instead; local environment restrictions do
not disable tools, plugins, or automatic sharing on that server. The script never
uses `--auto`, continues a session, or explicitly requests sharing. This is **not
a security sandbox**: trusted global and managed OpenCode configuration still
applies. Rejecting a tool-use event does not undo a tool action already allowed
by the server. Do not put private student information in generation prompts or
global instructions used by this workflow.

The adapter parses JSONL text events and validates the resulting sentence JSON.
Missing OpenCode, nonzero exits, errors, tool-use events, malformed responses,
and timeouts fail without silently falling back to invented content. It does
not retry generation automatically. Missing-executable launcher fallbacks follow
the rules above. A timeout stops the local launcher; with a container wrapper or
`--server`, downstream work may continue after a timeout or interruption. Check its
status before retrying to avoid duplicate requests and charges, or use a saved
bank. Default automated tests use mocked processes and a local Python fake
launcher; they never contact a provider. A real-provider smoke test is opt-in
via `--model`.

### Output Files

Explicit output paths replace existing files. Input JSON, saved JSON, worksheet,
and answer-key paths must be distinct. Failed sentence generation writes none
of these files. After successful generation, requested JSON is saved before PDF
rendering so it remains available if a later PDF write fails. Outputs are not a
multi-file transaction: a later failure can leave earlier completed files.

## Reusable Layout API

`worksheet.draw_instructions` wraps plain-text directions, and
`worksheet.draw_writing_line` draws either guide style while preserving the PDF
canvas's graphics state. `WritingExercise`, `WritingLayout`, and
`generate_writing_pdf` provide automatically paginated prompt-and-writing blocks.
For example:

```python
from worksheet import WritingExercise, WritingLayout, generate_writing_pdf

generate_writing_pdf(
    "practice.pdf",
    [WritingExercise("rain"), WritingExercise("train")],
    WritingLayout(
        title="Spelling practice",
        instructions="Read each word, then copy it.",
        lines_per_exercise=3,
        line_style="guided",
    ),
)
```

Missing-letter exercises, additional grammar activity types, and a complete
curriculum-aligned dictionary are not implemented in this first version.
